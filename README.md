# 歧路旅人 0 人物关系图谱

基于游戏资料整理的非官方人物关系可视化。通过人物、关系连线和原文对话，查看角色之间的联系及其在不同剧情片段中的变化。

**在线体验：[打开人物关系图谱](https://patricksr.github.io/octopath-traveler-0-relationships/)**

**剧透提示：包含全剧情人物身份、亲属关系、敌我变化及其他重要情节。**

## 功能

- 按人物姓名或别名搜索，归并同一人物的不同称号与身份。
- 按人物分组和关系类型筛选，点击人物展开直接关联。
- 拖动画布平移，使用滚轮、双指或按钮缩放；支持拖动人物节点。
- 点击关系连线，按章节或事件分组阅读相关原文；较长的记录可继续展开。
- 查看人物介绍、提及原文和相关对话。
- 使用灰蓝色区分主角的同行伙伴关系，亲属、发小等保留各自配色。
- 适配桌面和移动端，无需登录。

## 数据范围

当前版本收录：

- 225 个去重角色实体，包含具名人物、自定义主角、具名动物与神祇等；不是官方公布的人物总数。
- 204 条有原文支持的人物关系。
- 414 条单独分层的对话关联，默认关闭；这类连线不表示亲属、友好或敌对关系。
- 1,313 组原文片段，220 个角色已配图。

4 位未找到可靠图像的角色及可自定义主角使用占位图。部分人物尚未建立可靠关系线，不为连通全图而补造关系。

人物分组、关系标签和对话分组标题属于资料整理，不是官方人物关系表或官方命名。分组依据章节与事件，不代表完整、绝对的剧情时间轴。

## 使用方式

直接访问在线页面即可使用。仓库中的 `index.html` 是自包含网页，所需图片、样式、脚本与引用文本均已内嵌，也可直接离线打开。

公开版展示原文出处的路径、行号或文本编号，但不提供完整原始资料的下载链接。页面不依赖私有仓库访问权限。
